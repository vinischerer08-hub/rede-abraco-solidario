# Rede Abraço Solidário

Site responsivo para uma ONG fictícia, desenvolvido como projeto de portfólio. Apresenta uma causa, exemplos de atuação e formas de participação. Não recebe doações nem pedidos de atendimento.

## Tecnologias

HTML, CSS e JavaScript. O projeto não possui backend.

## Como executar

Abra o arquivo `index.html` no navegador. A fotografia e as fontes são carregadas de serviços externos e exigem conexão com a internet.

## Personalização

Edite os textos em `index.html`, as cores e o layout em `style.css` e o menu para celular em `script.js`. Antes de usar o site com uma ONG real, substitua o nome, os textos e a imagem e adicione canais de contato e doação verificados.

## GitHub Pages

Nas configurações do repositório, acesse **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)` e salve.
